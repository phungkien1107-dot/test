# Gian hàng hội chợ Ong Nhỏ

Web app tiếng Việt hỗ trợ lập kế hoạch gian hàng hội chợ: sản phẩm, chi phí, hòa vốn, kịch bản kinh doanh, bán thử và tổng quan.

## Cách chạy

Nhấp đúp vào file `index.html` để mở bằng trình duyệt. Ứng dụng không cần cài đặt, đăng nhập hay Internet.

## Chức năng chính

- Tab Tổng quan: chỉ số kế hoạch, biểu đồ so sánh kịch bản và xếp hạng sản phẩm.
- Sản phẩm & bán thử: nhập giá, chi phí, số lượng và lưu đơn bán thử.
- Chi phí & hòa vốn: theo dõi chi phí cố định, lợi nhuận và điểm hòa vốn.
- Kịch bản kinh doanh: so sánh Thận trọng và Cơ sở.
- Dữ liệu được tự lưu trên trình duyệt; nút Nạp dữ liệu mẫu sẽ khôi phục số liệu ban đầu.

## Dữ liệu mẫu

Doanh thu kế hoạch: 3.875.000 đ · Lợi nhuận dự kiến: 1.660.000 đ · Hòa vốn: 49 phần.
